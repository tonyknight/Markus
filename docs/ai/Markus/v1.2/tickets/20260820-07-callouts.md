## Description

Preview has no callout element, so a Custom callout color would be a lie. Parse GitHub-style alerts (`> [!NOTE]`, TIP, WARNING, IMPORTANT, CAUTION). One `tokens.callout` color for chrome (background/border/label). Types differ by keyword and SF Symbol, not five wells. Unknown `> [!FOO]` is a normal block quote. Not a fold type. If detection paints every quote as a callout, stop and reopen design (Requirements risk).
