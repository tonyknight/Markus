### T05: QoL chrome, scroll, Preview zoom
Fix Important review (do not mark the ticket done):
1. **Find/replace chrome.** Cmd+F (and a Find control) presents a find/replace bar or sheet. Find/replace still run on the full `NSTextStorage` (folded text included). Tests: present find chrome; with a heading folded, the chrome/host find action hits hidden body text; replace still saves full UTF-8.
2. **Go-to-line chrome.** Cmd+L (and a Go to Line control) presents a line field; confirming calls `goToLine` / `jumpToSourceLine` (source line map). Tests: present the chrome; confirming a later visible line sets caret/packed Y like the existing go-to-line test.
