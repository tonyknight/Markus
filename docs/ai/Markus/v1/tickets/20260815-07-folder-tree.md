### T05: Hold folder security scope
Keep **root** security-scoped access for the whole folder session (R8/N4). `openFolder` must `startAccessingSecurityScopedResource` on the root and **not** stop until the folder session is cleared (single-file open or another folder). `openRecent` must not `defer { stopAccessing }` after `openFolder` — that drops the scope before the user selects a child. Child `openTreeFile` stays `DocumentSession.open`; descendants are readable while the directory is accessed. Tests: after `openFolder` / `openRecent`, `FolderSession` reports it is still accessing the root; after `openPicked` of a lone file, root access is released; opening a child after recent-folder does not stop root access first. Do not rely on temp-dir readability as proof of sandbox.
Files: `FolderSession.swift`, `DocumentHost.swift`, `FolderSessionTests.swift`
Verify: `xcodebuild -project Markus/Markus.xcodeproj -scheme Markus -destination 'platform=macOS' -only-testing:MarkusTests test`
then iPhone 17 and iPad Pro 13-inch (M5) same as T04.
