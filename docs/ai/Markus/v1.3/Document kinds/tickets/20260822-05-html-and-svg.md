### T01: Shared HTML/XML tokenizer → element folds + outline + diagnostics + budget

Byte-offset HTML/XML tokenizer (one engine). Walk UTF-8, track 1-based lines the same way `JSONScanner` / `SourceMap` do (`\n` only). `HTMLScanDialect.html` is case-insensitive with HTML5 void + rawtext (`script`/`style`/…). `HTMLScanDialect.xml` is case-sensitive, no HTML void list, understands CDATA (SVG). Fold an element only when a matching end tag lands on a later line than the opener. Void tags and `/>` self-closing tags are not foldable. `Block.kind` is `MarkdownBlockKind.other`. `FoldID.Kind` gains `element`. Fold extent is `openerEnd..<closerEnd` (opener line stays visible, same as fences/JSON). Outline: tag name plus `#id` / first `.class` when those attributes are cheap to read. Diagnostics for unclosed/malformed/mismatched tags (capped). `HTMLScanBudget` mirrors `JSONScanBudget` (max bytes, foldables, outline, spans, 50 ms). Over budget: stop, keep partial folds, warning diagnostic.

Files: `Markus/Markus/Syntax/HTMLScanner.swift`, `Markus/Markus/Markdown/BlockIndex.swift`

### T02: HTMLSyntaxProfile / SVG factory wiring

`HTMLSyntaxProfile` wraps the shared scanner. `analyze` uses `HTMLScanBudget.default`. Factory: `html` dialect for `.html`, `xml` dialect for `.svg` — not a second engine. `SyntaxProfiles.profile(for:)` returns that profile for both kinds. Empty buffer does not crash.

### T03: Locked WKWebView Preview overlay; session stays mounted

`ContentView.editorColumn` keeps `SessionEditorRepresentable(session:)` in the hierarchy for every kind. When kind is html/svg, overlay a locked `WKWebView` (hidden in Source, visible in Preview via opacity / `allowsHitTesting`). Do not `if preview { WebView } else { SessionEditorRepresentable }`. Load with `loadHTMLString(_:baseURL: nil)` (SVG wrapped in a minimal HTML shell). `allowsContentJavaScript = false`. Navigation delegate cancels `http`/`https`/`file` and link-activated navigations. Non-persistent data store. Treat the buffer as untrusted (N5). `FoldingSession.rebuildSubstitutionIndex` stays Markdown-only so HTML Preview is not GFM substitution. HTML/SVG already open in Source via `applyKind`.

Files: `Markus/Markus/Preview/LockedHTMLPreview.swift`, `Markus/Markus/ContentView.swift`, `Markus/Markus/Editor/FoldingTextView.swift`

### T04: Refresh WebView from buffer without unmounting; iOS+Mac

The html/svg WebView stays mounted across Source/Preview (only opacity/hit-testing change). `updateNSView` / `updateUIView` reloads from the current buffer string without recreating the `WKWebView` or the FoldingTextView. Debounce reloads (~120 ms, same spirit as editor reparse) so typing does not thrash; do not drop the document session. Same lockdown on iOS and Mac.
