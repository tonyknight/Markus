# Markus

A free, open-source, native macOS Markdown editor.

Markus is aimed at long documents: the same native, file-based, no-telemetry feel as a fast AppKit editor, plus **heading and fenced-code folding** so you can collapse what you are not working on.

This repository is MIT-licensed. It currently holds the project plan, not the app yet.

## Start here

Read **[docs/PLAN.md](docs/PLAN.md)**. That is the product brief, Editorio capability map, architecture recommendation, and phased plan.

## What this is not

- Not a fork of [Editorio](https://editorio.crncevic.org) (closed-source; public docs only).
- Not a PKM / vault app.
- Not Electron.
